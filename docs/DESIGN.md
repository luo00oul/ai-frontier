# AI 前沿探索：研究者的数字笔记本

本次基于仓库 ed86179 的真实 HTML/CSS 与浏览器页面检查；用户本条消息没有新增附件。目标是把论文、问题、实验和笔记放在视觉中心，采用中性纸面、墨绿强调色、窄行正文、低装饰组件。

## 现状诊断：五个具体问题

1. **首屏重心分散**。原 `.cover-feature` 栅格为 `1.13fr 1fr`，概念图占比接近正文；标题和大幅插图争夺注意力。改为 `1.7fr 1fr`，手机隐藏辅助图；标题下直接给问题、15 分钟与论文数量。
2. **字号层级不适合持续阅读**。原品牌 33px、主标题最高 57px，而来源、标签、日期和说明大量采用 10–12px。把主标题降至最高 44px，品牌 24px，功能信息一般为 14–16px；仅英文品牌副标、图注等保留 12px。
3. **长文的行宽和节奏偏松**。原正文区域最大 740px，段落 17px / 2.05，约 43 个全角字符一行。改成 648px、18px / 1.85，约 36 个汉字；手机 17px，行宽随屏幕自然变窄，不能同时要求手机显示 36 个字。
4. **间距缺乏可复用规则，手机操作离拇指较远**。原样式混用 62、65、23、41px 等间距；主导航位于页面顶部。采用 4px 基数、8px 主节奏；手机主导航固定底部，各项最少 48px 高，并预留 safe-area 和正文底部空间。
5. **颜色散落，装饰和深色支持不一致**。原来 `color-scheme: light`，且正文、插图、输入框分散使用硬编码蓝色、浅蓝与白色，绿色贴签和星形装饰增加噪声。改为语义变量、系统深色媒体查询，删除贴签与星形装饰；SVG 也使用同一配色变量。

## 页面改造

- **本周探索**：问题优先；显示阅读时长、论文数量，论文计数来自 kind 为论文或预印本的来源，不把产品公告计为论文。
- **阅读页**：窄行正文；桌面侧目录，手机顶部可横滑目录；顶部进度条与文字百分比按 article 区域计算；行内引用保留下划线；增加“我验证了什么”输出区。
- **归档**：日期轴与内容行排版，搜索和兴趣筛选继续保留；没有伪造历史条目。
- **手机**：底部主导航 48px，控件至少 44px，底部留出导航和 safe-area 的空间；toast 显示在导航之上。

## 修改文件与使用方式

- `site/assets/style.css`：可整份替换的独立 CSS，无 import、字体网络请求、框架或预处理器。
- `site/index.html`：增加 light/dark color-scheme 与 theme-color meta；加载文字具有 role=status。
- `site/assets/app.js`：首页问题与论文计数、目录文字进度、实际实验观察、当前页 aria-current、140ms 页面进入动画。数据路由与 localStorage key 保持原值。
- `site/assets/mark.svg`：开本线稿标记，自动适配深色。

主导航、专题、正文、论文、笔记的现有结构保留。仅替换 CSS 即可获得版式与双主题；论文数量、验证观察、文字进度需要配套 JS 模板更新。现有 Pages 的 Python 步骤只负责复制与资源版本标记；CSS 本身不依赖构建。

## 细节与验证

- 链接有下划线、选中导航同时有字重/背景变化，避免只依靠颜色辨认。
- focus-visible 为 2px 描边加 4px 外偏移；按钮不因 hover 移动。
- 页面切换 140ms、3px 的轻微进入动画，prefers-reduced-motion 下禁用。
- 加载态写“正在读取本期研究手记…”，使用静态短线提示，不持续闪烁。
- 两套主题均在浏览器真实 prefers-color-scheme 条件下检查，手机测试视口内容宽 375px，未见页面横向溢出。
- 桌面文章测得字体 18px、行高 33.3px、内容宽 648px。
- 原有笔记可读取；深色手机归档搜索与模型实验正常。
